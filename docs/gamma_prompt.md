# 어떻게 만들었나

설계에서 지킨 원칙 세 가지.

**1. 계산을 엔진에서 떼어냈다**

정확도 · 효율 · 일관성 가중합. 약점은 계산이 찾고, AI는 문장으로 옮깁니다.
