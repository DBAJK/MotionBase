# 어떻게 만들었나 — 세 가지 원칙

**원칙 ① 게임 규칙과 점수는 화면과 분리**
공의 결과 · 점수 계산을 VR 화면 · 컨트롤러와 떼어 설계
장비 없이 PC에서 먼저 확인 · 스포트랙으로 옮겨도 그대로 사용

**원칙 ② 판정은 실제 움직임으로**
타격 — 손이 아니라 배트 끝 속도 측정 (v_tip = v_hand + ω × r)
백업 판단 — 버튼으로 답을 고르지 않고 그 자리까지 직접 이동

**원칙 ③ AI는 규칙 뒤에**
약점 · 정답은 규칙이 결정, AI는 설명 담당
AI가 없거나 늦어도 게임은 계속 · 보정 전 기준값은 "미보정" 표시

**개발 방식**
2인 분담 — 타격 · AI 코치 / 수비 미션 · 화면과 조작
규칙과 점수를 떼어 둔 덕분에 동시에 개발
틀리면 안 되는 규칙은 자동 테스트 18개로 확인

**해결한 문제 — 백업 판단 화면 끊김**
원인: 동료 수비수 6명의 몸을 부위마다 따로 그림
해결: 같은 모양끼리 묶어 한 번에 그리기
**그리기 요청 186회 → 최대 12회**

**사용 기술**
Unreal Engine 5.8 · C++ · OpenXR · 생성형 AI(Claude API)

# AI 코치와 점수 — 다시 도전하게

[게임 화면 스크린샷 자리]

과제의 **생성형 AI 활용** 부분

**원칙 — 틀린 야구를 가르치지 않도록**
약점은 규칙이 먼저 판단 · AI는 그 결과를 사람 말로 풀어줌

**AI 코치가 하는 일 3가지**
1. 종목마다 다른 조언 — 공을 놓친 사람과 자리를 잘못 잡은 사람은 다른 조언
2. 플레이마다 "왜 거기가 내 자리였는지" — "송구가 3루로 가니까, 빠질 때를 대비해 누군가 뒤에 있어야 한다."
3. 최근 5판의 기록으로 반복되는 약점 · 추천 운동(세트 · 횟수)

**다시 하고 싶게 만드는 점수**

# 직접 플레이해 보여드립니다

라이브 시연 · 2분 · PC 화면으로 진행 (실제 플레이는 VR 헤드셋 기준)

**시연 순서**
- 메뉴 — 게임 선택
- 타격 — 한 타석 승부, 실력에 따라 바뀌는 공
- 결과 — 약점 리포트 · 추천 운동
- 수비 — 포구 미션 → 송구 미션
- 종합 점수 → AI 코치

**보실 포인트**
- 실력을 따라오는 난이도 — 결과에 따라 달라지는 공
- 랜덤이 아닌 파울 — 타이밍에서 계산된 결과
- AI 없이도 나오는 약점 — 리포트와 추천 운동은 규칙으로 먼저, AI는 문장만

# 스포트랙에 맞추기 위한 개선

**지금 모습 그대로는 스포트랙에 들어갈 수 없습니다. 개선이 필요합니다.**

| 지금 버전 | 스포트랙 |
|---|---|
| VR 헤드셋으로 보기 | 헤드셋 없이 바닥 투사 화면으로 보기 |
| Vive 컨트롤러로 조작 | LiDAR 위치 인식 |
| 기기 하나 · 한 사람 중심 | 여러 명이 한 공간에서 함께 |

**그대로 가져가는 것**
게임 규칙 · 점수 · AI 코치 — 입력 장치와 분리해 설계
(개발 기간에는 LiDAR 장비를 쓸 수 없어 대여받은 HTC Vive Pro로 먼저 구현)

**바꿔야 할 것 3가지**
1. 입력 — Vive 컨트롤러 → LiDAR 위치 인식 (배트는 소품에 트래커를 붙이는 방식 검토)
2. 화면 — 헤드셋 시점 → 바닥 투사 시점으로 재구성
3. 함께 하기 — 여러 명 동시 플레이 · 사람별 기록 (백업 판단에 협동 구조 도입, 접속 화면·경쟁 요소는 다음 단계)

점수 기준값 — 실측 보정 전(화면에 "미보정" 표시), 실제 플레이 데이터로 보정 예정

## B. 짧은 프롬프트 (Generate 모드 — 품질은 A보다 떨어짐)

```
㈜뉴작의 XR 피트니스 보드게임 "스포트랙(SporTrack)"에 들어갈 새 야구 게임 섬을
개발한 결과 보고 발표 자료를 10장으로 만들어줘. 한국어, 7분.
트레이닝 도구가 아니라 게임으로 소개한다("훈련·연습" 대신 "게임·미션·도전·기록").
톤은 전문적이되 딱딱하지 않게. 슬라이드 문체는 개조식으로 통일.
현재 버전은 VR 헤드셋 기반이므로 "헤드셋 없이"를 현재 기능처럼 쓰지 말 것.

1) 표지 — "공이 무섭지 않고, 타격에서 끝나지 않는 야구" / 팀 MotionBase · 팀장 김재경 · 2인
2) 과제와 우리의 선택 — 스포트랙은 16개 스포츠 섬을 주사위로 도는 협동·경쟁 XR 보드게임
   (CES 2026 XR 공간 컴퓨팅 혁신상). 과제는 새 섬 하나. 초보자에게 야구공은 딱딱하고
   빗맞으면 손이 울려 아프다 + 야구 체험은 대부분 타격에서 끝난다
   + 야구는 혼자 하기 어렵다(캐치볼도 상대가 필요, 경기는 18명). 스포트랙은 여럿이 팀으로 즐기지만 이 섬은 혼자서도 한 판
   → "공에 다칠 걱정 없이, 타격에서 끝나지 않게, 혼자서도 한 판이 되게"
3) 무엇을 만들었나 — 게임 4종 표(게임 · 하는 일 · 판정): 타격 / 포구 미션 / 송구 미션 / 백업 위치 판단 미션.
   한 판의 흐름(게임 선택 → 난이도·타석 → 플레이 → 결과 화면 → 다시 하기/메뉴 → 종합 점수 → AI 코칭),
   공통 장치(약점 리포트·추천 운동·종합 100점·3D 메뉴·기록 저장). 분야1 목표. 현재 버전은 VR 헤드셋 + Vive 컨트롤러 기반
4) 어떻게 만들었나 — 원칙 3개(규칙·점수를 화면과 분리 / 판정은 실제 움직임으로 / AI는 규칙 뒤에),
   2인 분담과 자동 테스트 18개, 해결한 문제(백업 판단 화면 끊김: 그리기 요청 186회 → 최대 12회), 사용 기술
5) 게임 ① 타격 — 한 타석 승부(볼카운트·삼진·볼넷, 홈런·안타·파울). 실력을 따라오는 난이도(분야1),
   어려운 단계 점수 보너스. 진짜 공이 아니라 손 울림이 없고, 타이밍·스위트스팟을 화면으로 보여준다
6) 게임 ② 수비 미션 3개 — 포구(성공·헛손질·놓침) / 송구(게이지로 목표 베이스 명중, 전환 시간) /
   백업 위치 판단(7포지션, 제한 시간 안에 맞는 자리로 이동, 23가지 상황)
7) AI 코치와 점수 — 규칙이 약점을 찾고 AI는 풀어서 말한다. 종목별 조언 / 플레이 해설 / 최근 5판 추세 + 추천 운동.
   종합 100점은 종목별 최고 기록으로 산정. 하단에 "한 판 → 코치 → 다시 도전 → 기록 경신" 순환 다이어그램
8) 라이브 시연 예고 (2분, PC 화면으로 진행)
9) 스포트랙에 맞추기 위한 개선 — 지금(VR 헤드셋·Vive 컨트롤러·기기 하나) vs 스포트랙(바닥 투사·LiDAR·여러 명)
   비교 도식. 그대로 가져가는 것(게임 규칙·점수·AI 코치) / 바꿔야 할 것 3가지(입력·화면·함께 하기와 사람별 기록)
10) 마무리 — 옮겨도 남는 것, 교육과정 매핑, 다른 종목 섬으로 확장

디자인: 야구 스포츠 감성 + 게임 UI 느낌(전광판 점수, 미션 카드, 난이도 배지). 야간 경기장 무드.
다크 배경, 야구장 그린 + 베이스 옐로 2색 포인트. 스톡 사진 대신 그래픽 모티프.
5·6·7번은 게임 화면 스크린샷 자리를 크게 비워 둔다.
숫자는 그대로 유지하고, 없는 게임 기능(랭킹·대전·보상·단계 해금)을 지어내지 말고,
"AI가 학습한다"·"위험이 전혀 없다"는 표현은 쓰지 말 것.
```

## C. 감마 결과 받은 뒤 반드시 확인할 것

1. **숫자·고유명사 검증** — 감마가 자주 바꾼다
   `16개 스포츠 섬` / `CES 2026 XR 공간 컴퓨팅` / `7개 포지션` / `23가지 상황` / `최근 5판` / `공격 50 + 수비 50` / `186회 → 최대 12회` / `자동 테스트 18개` / `C++ 약 2만 2천 줄`
   ※ "스포트랙"을 "스포츠트랙"으로 바꾸는 오류가 잦다
2. **없는 게임 기능이 끼어들었는지** — 게임처럼 보이게 하라고 하면 감마가 "랭킹", "레벨업", "보상", "대전 모드"를 지어내기 쉽다. 전부 삭제.
3. **"헤드셋 없이"가 현재 기능처럼 들어갔는지** — 현재 버전은 **VR 헤드셋 기반**이다. 표지·3번·10번을 특히 볼 것.
4. **안전 표현 과장** — "완벽히 안전", "위험 제로"로 바뀌었으면 "공에 다칠 걱정 없이"로 되돌릴 것.
5. **9번의 비교 도식이 살아 있는지** — "지금 모습 그대로는 들어갈 수 없다" 문장이 흐려지면 발표 전체가 과장으로 보인다.
6. **과제 대응 문구가 살아 있는지**
   - "분야 1 — 연령 맞춤형 난이도 조절" (3번·5번)
   - "과제의 생성형 AI 활용 부분" (7번)
   - "협동 구조 도입, 접속 화면·경쟁 요소는 다음 단계" (9번)
7. **AI·기록 표현 과장** — "AI가 학습해 점점 똑똑해진다", "다시 방문하면 내 기록을 이어서" 같은 표현은 삭제.
8. **문체 섞임** — 한 카드 안에 "~다 / ~습니다 / ~니까."가 섞였으면 개조식으로 맞출 것.
9. **5·6·7번 스크린샷 자리** — 작게 잡혔으면 크게 키울 것
10. **3·4번 도식** — 3번 "한 판의 흐름" 화살표 순서와 4번 186 → 12 비교가 빠지거나 뒤섞였으면 되돌릴 것
11. **발표자 노트는 안 넘어간다** — 대본은 `script_7min_final.md`에 있다
