# 손 속도가 아니라, 배트 헤드 속도

**문제**
컨트롤러(손) 속도 ≠ 배트 속도. 회전 채찍 효과로 배트 헤드가 손보다 빠릅니다.

**v_tip = v_hand + ω × r**

MotionController 자식 BatTip을 배트 길이만큼 오프셋 → 손 위치 미분에 쿼터니언 델타 각속도를 더합니다. 링버퍼 45샘플에서 컨택 순간 속도와 피크 속도를 뽑습니다.

**컨택 판정 2관문**
관문 ① 시간 창 — | t − 이상 컨택 시각 | ≤ 0.32s
관문 ② 동작 게이트 — 중앙차분 속도 ≥ 1.5 m/s

→ 배트를 가만히 들고 있으면, 공이 지나가도 컨택되지 않습니다.

히트박스도 점이 아닙니다. 배럴 선분 44cm와 공 사이의 최단거리로 판정합니다.

# 약점은 계산이 찾고, AI는 옮깁니다

**TotalScore = 0.4 · 정확도 + 0.35 · 효율 + 0.25 · 일관성**

- 정확도 — exp(−err² / 2σ²) × 거리 감쇠 · 타이밍 오차 + 스위트스팟 이격
- 효율 — 가상 타구 속도 정규화. 배트 속도만으로는 주지 않습니다
- 일관성 — 정확도 표준편차. 작을수록 고득점

헛스윙은 0점 · 기준 상수는 FScoringConfig로 분리 — 미보정 상태면 결과 화면에 "미보정"이 그대로 표시됩니다.

파이프라인:
플레이 데이터 → UWeaknessDetector(결정론적 임계값 비교 → 약점 축 18종) → UDrillCatalog(축별 추천 드릴) → 생성형 AI(근거 숫자를 문장으로만 변환)

**AI는 숫자를 지어낼 수 없는 구조입니다. API 키가 없어도 약점 리포트와 추천 드릴은 그대로 나옵니다.**
